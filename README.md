# 🎓 Udemy Clone Website

This is a **simple Udemy clone website** built using **HTML5 and basic CSS**.  
The project replicates the basic layout and design of the Udemy platform for **learning and practice purposes only**.

## 🛠️ Technologies Used
- HTML5  
- CSS3 (Basic styling)

## ✨ Features
- Homepage layout inspired by Udemy  
- Course listing sections  
- Clean and minimal UI design  
- Beginner-friendly code structure  

## 🎯 Purpose
This project is created **only for educational purposes** to practice front-end development skills using HTML and CSS.  
It is **not affiliated with or endorsed by Udemy**.

## 🚀 How to Run
1. Clone or download this repository  
2. Open `index.html` in any web browser
